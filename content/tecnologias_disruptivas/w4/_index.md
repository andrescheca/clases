## Ética y Tecnología

{{% fragment class="bullet-point" %}} El avance tecnológico implica **responsabilidad social** {{% /fragment %}}
{{% fragment class="bullet-point" %}} Riesgos: manipulación algorítmica, sesgos, privacidad, automatización sin control {{% /fragment %}}
{{% fragment class="bullet-point" %}} Dilemas: ¿cuándo se justifica usar IA? ¿quién es responsable de sus decisiones? {{% /fragment %}}

{{% note %}}
Discute ejemplos: IA en justicia, deepfakes, decisiones de crédito automatizadas.  
Anima a debatir: ¿toda innovación es buena por defecto?
{{% /note %}}

## Amenazas y vulnerabilidades

{{% fragment class="bullet-point" %}} **Amenazas**: malware, phishing, ransomware, ingeniería social {{% /fragment %}}
{{% fragment class="bullet-point" %}} **Vulnerabilidades**: errores de software, configuraciones inseguras, falta de actualizaciones {{% /fragment %}}
{{% fragment class="bullet-point" %}} **Ataques comunes**: DDoS, secuestro de sesiones, fuga de datos personales {{% /fragment %}}

## Ley de Protección de Datos (Ecuador)

{{% fragment class="bullet-point" %}} Ley vigente desde 2021: **LOPDP** (Ley Orgánica de Protección de Datos Personales) {{% /fragment %}}
{{% fragment class="bullet-point" %}} Inspirada en GDPR (Unión Europea) {{% /fragment %}}
{{% fragment class="bullet-point" %}} Principios: consentimiento, minimización, finalidad, seguridad, confidencialidad {{% /fragment %}}
{{% fragment class="bullet-point" %}} Derechos: acceso, rectificación, eliminación, oposición {{% /fragment %}}

{{% note %}}
Revisa el reglamento, derechos del titular de los datos y sanciones.
{{% /note %}}

## Normas y marcos de ciberseguridad

{{% fragment class="bullet-point" %}} **ISO/IEC 27001**: gestión de seguridad de la información {{% /fragment %}}
{{% fragment class="bullet-point" %}} **NIST Cybersecurity Framework**: identificación, protección, detección, respuesta y recuperación {{% /fragment %}}
{{% fragment class="bullet-point" %}} **CIS Controls**: buenas prácticas priorizadas {{% /fragment %}}

## Buenas prácticas personales

{{% fragment class="bullet-point" %}} Usar contraseñas seguras y autenticación multifactor {{% /fragment %}}
{{% fragment class="bullet-point" %}} Actualizar sistemas y software regularmente {{% /fragment %}}
{{% fragment class="bullet-point" %}} No compartir información personal en redes sin necesidad {{% /fragment %}}
{{% fragment class="bullet-point" %}} Evitar enlaces o archivos sospechosos {{% /fragment %}}

{{% note %}}
Puedes hacer una mini actividad en vivo:  
¿Tus contraseñas aparecen filtradas? Revisa en https://haveibeenpwned.com  
Analiza políticas de seguridad en tu entorno (ej. universidad o empresa).
{{% /note %}}

{{% fragment class="bullet-point" %}} La tecnología tiene impacto ético y legal que no puede ignorarse {{% /fragment %}}

{{% fragment class="bullet-point" %}} Existen marcos legales y técnicos que orientan el uso responsable de datos y sistemas {{% /fragment %}}
